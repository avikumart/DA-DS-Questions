# DA-DS-Questions

**A Comprehensive Series of Questions and Answers for Data Analysts and Data Scientists**

This repository is a curated collection of interview questions, fundamental concepts, practice problems, and solutions covering the core technological stack required for Data Analyst (DA) and Data Scientist (DS) roles. It serves as an excellent resource for preparing for technical interviews, reinforcing foundational knowledge, and exploring practical implementations of data-related tools and techniques.

---

## 🚀 Key Topics Covered

The repository is structured into folders, each focusing on a specific technology or domain within the data analytics and data science ecosystem.

| Topic | Description |
| :--- | :--- |
| **Python** | Core Python programming questions and general concepts. |
| **Pandas** | Data manipulation and analysis using the powerful Pandas library. |
| **Numpy** | Numerical computing, array operations, and vectorization techniques. |
| **SQL and databases** | SQL queries, database concepts, joins, and optimization. |
| **Excel** | Essential Excel functions, pivot tables, and data cleaning techniques. |
| **Statistics** | Foundational and advanced statistical concepts crucial for data analysis. |
| **data visualisation with matplotlib and seaborn** | Creating effective static and interactive data visualizations. |
| **Web-scraping** | Techniques and tools for extracting data from websites. |
| **R_codes** | Code examples and practice problems implemented in the R programming language. |
| **Azure-pyspark-data-analysis** | Solutions and notes for big data analysis using PySpark on the Azure cloud platform. |

---

## 🛠️ Tech Stack & Languages

The content primarily revolves around the following technologies:

* **Languages:** Python, R, SQL
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, PySpark
* **Tools:** Microsoft Excel
* **Platform:** Azure Cloud Services

## 💡 How to Use This Repository

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/avikumart/DA-DS-Questions.git](https://github.com/avikumart/DA-DS-Questions.git)
    ```
2.  **Navigate to a Topic:** Browse the folders to find the specific area you want to study (e.g., `Pandas`, `SQL and databases`).
3.  **Review Questions and Solutions:** The content is primarily delivered in Jupyter Notebooks (`.ipynb`) and other document formats (`.pdf`), providing a mix of questions, explanations, and executable code.
